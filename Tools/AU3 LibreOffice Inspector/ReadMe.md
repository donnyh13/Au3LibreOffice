# Au3 LibreOffice Inspector

While working on the LibreOffice UDF I have used the following tools quite extensively. In case anybody else would find some help while toying with the LibreOffice API, these tools are included here. The LibreOffice Xray and MRI extensions allow you to inspect Objects and Properties in the LibreOffice API. These included functions allow you to do it directly from an AutoIt Script, instead of having to use a Macro directly in LibreOffice. They're nothing fancy.
Either Xray or MRI will work, the Xray tool is the one I primarily use, only because it was the first tool I found, but it doesn’t seem to be maintained much any more. MRI seems to have been more recently updated, and perhaps is still maintained.

## Prerequisites

In order to use these tools, you must have LibreOffice **Installed**, and have either the **Xray Tool extension** and/or the **MRI extension** installed according to their respective instructions. You may have both installed at once, and can use both as needed.
